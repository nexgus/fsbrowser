# v0.1.0

## New Feature(s)
- Initial release of fsbrowser, a protocol-agnostic file browsing component for Wails v3 desktop apps, shipped as a Go module plus Vue 3 and React frontend packages.
- Directory browsing with path-centric navigation (editable path bar, parent / home buttons).
- File or directory picking, single or multiple selection, chosen per invocation.
- Directory management: create directory, inline rename, batch-capable delete.
- Context menu with common actions (rename, delete, copy path, create directory, refresh, hidden-file toggle).
- Multiple roots with a root switcher; hidden on single-root systems.
- Link-aware icon set covering links to files and directories, sockets, FIFOs, device files, and broken links.
- Errors shown in a fixed-height status bar and reported to the host app in structured form; no popups are ever opened.
- Built-in light and dark themes, customizable via a flat variable table.
- Localization support: English built in, extensible to other languages via locale packs (Traditional Chinese included).
- Windows and macOS host support.
- Runnable React and Vue 3 example apps demonstrating local and SSH-backed file systems.
