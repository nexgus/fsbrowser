# v0.4.0

## New Feature(s)
- Add cut, copy, and paste, with updated context menus, keyboard shortcuts, and new toolbar buttons; enabled once the host implements the new optional copy, move, and cancel capabilities.
- Add a warning callback for non-error notices such as a blocked nested paste.

## Change(s)
- Add a `canceled` error code for canceled copy/move operations.
- Add message keys for the clipboard operations and the two new toolbar buttons.
- Enable modifier-key multi-select in single return mode and save mode.
- Add a message key for the status bar hint shown when single mode has more than one item selected.

## Fix(es)
- Fix misaligned labels in the context menu.
- Fix directory sizes never being displayed.
- Fix the Vue 3 context menu not matching React on a file row.
